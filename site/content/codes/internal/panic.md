---
title: "internal/panic"
description: "yuanme crashed while processing a file."
---

yuanme crashed while processing a file. This is a bug in yuanme, not in the project.

## Example

```
Any file can trigger it, if it reaches a bug in a parser or a renderer.
```

## Fix

Report it at https://github.com/yuann3/yuanme/issues with the file named in the message. Until it is fixed, changing the construct near the reported place usually avoids it.
