A Page links to, or loads, a URL of the Site where nothing is: no Page, Static file or asset of the build. Links to other origins aren't checked.

## Example

```
<img src="/img/cat.png">
(with no static/img/cat.png)
```

## Fix

Correct the URL, here perhaps to the Static file's, or create the file.
